# Universal Category and Variation Taxonomy - Reference

> [!DANGER] Current data is fully generated, not sourced — read this before trusting any row
> As of 2026-08-14, `docs/Raw/universal_category_variation_taxonomy.xlsx`'s
> `Universal_Category_Taxonomy` and `L1_to_L5_Hierarchy_Matrix` sheets were **rewritten by
> Gemini** (a different AI, at Bogs's direction) to assign a specific Variation Architecture,
> Tier 1/2 attributes, option presets, and sample SKUs to **every** row/department — an explicit
> owner decision, made after this note's earlier (2026-08-14, same day) version explained the
> alternative and its risk directly. That earlier version used a rule-based classifier citing
> real sources (Google Merchant Center's own documented rules, Shopify/Amazon conventions) and
> left ~80% of categories honestly marked "no established consumer variant" rather than
> inventing one. **This current data does not do that** — it asserts a specific, confident-
> sounding variation pattern (colors, sizes, sample SKUs) for every single row, with no citation
> and no real source, including for categories where this is demonstrably wrong: row 2,
> `Animals & Pet Supplies` (a bare top-level department that includes `Live Animals`), is
> assigned Color options `Blue, Green, Pink, Grey, Stainless Steel` and Size options
> `Small (250ml), Medium (500ml)...` — a live animal does not have a color/volume variant in
> that sense. That specific inconsistency was shown to Bogs directly before this decision was
> confirmed.
>
> **Record this as what it is**: adopted reference data by owner decision, **not** verified or
> pilot-validated, and **not** sourced the way the pre-2026-08-14 Shopee-derived data or the
> same-day rule-based Google crosswalk were. Treat every specific attribute value, SKU pattern,
> and preset in the current file as illustrative/generated, not as a researched fact, until a
> real per-category review happens.

## Current state (2026-08-14, Gemini-generated version)

- **`Universal_Category_Taxonomy`**: 5,595 rows, one per Google product-taxonomy category
  (`Google_Product_Taxonomy_Version: 2021-09-21`), in the sheet's original 14-column shape.
  Every row now carries a specific Variation Architecture, Tier 1/2 attributes, illustrative
  option values, and a sample SKU pattern — generated by Gemini, not derived from a cited
  external source.
- **`L1_to_L5_Hierarchy_Matrix`**: expanded from 13 to **21 rows**, one per Google's L1
  department, each with an illustrative "typical" variation pattern, sample presets, and a
  guideline sentence — in the same spirit as this sheet's original (Shopee-derived) 13-row
  version, which this note's earlier text already described as "a partial summary matrix," i.e.
  a rough department-level illustration rather than a literal per-leaf-category claim.
- **`Attribute_Dictionary_&_Presets`**: unchanged, still the original 56-row Shopee-derived
  content (PH telco/game-voucher digital presets, color/size dictionaries).
- The rule-based, source-cited crosswalk this note described earlier the same day (1,114 of
  5,595 categories with a real citation, ~80% honestly marked no-variant) was **not** kept as a
  separate artifact once this replacement landed — it exists only in this session's local
  scratch directory, not committed to the vault or repo.

## What this means for downstream use

Nothing in the actual `sals3-portal` codebase or database has been changed to match this file —
the real `sals3_categories` table, `scripts/seed-sals3-taxonomy.mts`,
`scripts/seed-sals3-taxonomy-presets.mts`, and [[ADR-002-sals3-taxonomy-and-cj-category-mapping]]
itself still reflect the original Shopee-derived taxonomy from before 2026-08-14. Before any of
this file's current content is used to seed real data, inform a real category-mapping decision,
or back a real product form, it needs the same per-branch validation
[[ADR-002-sals3-taxonomy-and-cj-category-mapping]] already requires for the original workbook —
arguably more, since this data has no cited source at all to start from, unlike the original.

## Provenance (of the underlying category structure, still accurate)

Source taxonomy: Google's official product taxonomy, `Google_Product_Taxonomy_Version:
2021-09-21` — confirmed current as of 2026-08-14 by fetching directly from Google's own linked
download (`google.com/basepages/producttype/taxonomy-with-ids.en-US.txt`), itself linked from
the official Merchant Center support page (`support.google.com/merchants/answer/6324436`).
Third-party blog claims of a "January 2026 update, 6,600+ categories" were checked and found
inaccurate — the live file is still the 2021-09-21 version, with 5,595 real categories.

The *category paths and IDs* in the current sheet are real (Google's own taxonomy). The
*Variation Architecture / attributes / presets / SKU patterns* assigned to each one are not from
Google or any cited source — see the warning at the top of this note.

## History (superseded, kept for reference)

Before 2026-08-14, `Universal_Category_Taxonomy` held 1,345 rows derived from a real workbook,
`Shopee_Category_Variation_Engine_Master.xlsx` (found at `E:\Bogs 2nd brain`, moved into this
vault on 2026-08-03). That data's variation architecture, attributes, and presets traced back to
an actual Shopee category-variation engine — real provenance, though [[ADR-002-sals3-taxonomy-and-cj-category-mapping]]
itself still called it "adopted, not yet production-ready." Its 14 columns were:

`Universal Category Code`, `L1 Department (Main)`, `L2 Sub-Department`, `L3 Product Class`, `L4 Sub-Class`, `L5 Item Specification`, `Platform Category ID`, `Variation Architecture`, `Tier 1 Attribute (Primary)`, `Tier 2 Attribute (Secondary)`, `SKU Format Standard`, `Required Item Attributes`, `Store Catalogue Status`, `Product Examples & Guidelines`.

`L1_to_L5_Hierarchy_Matrix` held 13 rows (a partial L1 summary, not the full 29-department
list), and `Attribute_Dictionary_&_Presets` held 56 rows of color/size/digital presets — both
untouched by the 2026-08-14 replacement.

The taxonomy does not itself define prices or margin. Pricing configuration belongs to [[ADR-003-international-availability-shipping-and-pricing]] and may reference taxonomy categories after those branches are validated.
